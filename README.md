# ⚡ Regulated Power Supply for Amplifier Biasing

## 📌 Overview
This project focuses on designing a **5.1V regulated power supply** to bias an amplifier circuit operating at a specific Q-point.

---

## 📝 Problem Statement
Design a regulated power supply with:
- Output Voltage: 5.1V  
- Load Current: 50 mA  
- Ripple: < 2%  
- Application: Biasing an amplifier  

The amplifier must operate at:
- VCE = 3V  
- IC = 2.5 mA  

---

## 🎯 Objectives
- Convert AC to stable DC supply  
- Minimize ripple using filtering  
- Maintain constant regulated output  
- Provide stable biasing for amplifier  

---

## ⚙️ System Design

### 🔌 1. Transformer Stage
- Steps down AC voltage  

### ⚡ 2. Rectifier Stage
- Converts AC to pulsating DC  

### 📉 3. Filter Stage
- Reduces ripple using capacitor  

### 🔋 4. Voltage Regulation
- Provides stable 5.1V output  

---

## 🧠 Concepts Used
- Rectifiers (Full-wave)
- Ripple reduction
- Voltage regulation
- Q-point biasing
- Analog circuit design

---

## 📊 Results
- Achieved regulated 5.1V output  
- Ripple maintained below 2%  
- Stable biasing for amplifier  

---

## ⚠️ Observations
- Minor ripple due to capacitor limitations  
- Component tolerances affect output  

---
